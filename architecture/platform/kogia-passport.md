# Kogia Passport

> A digital human development profile — not a government document.

The single strongest long-term asset in the ecosystem. It is what turns Kogia from
a collection of products into one thing.

## The journey it records

```
Child in Kogia Education        →  Learning Profile
Grows                           →  Skills Profile
Learns a skill                  →  Achievement ✓
Passes an assessment            →  Verified Skill ✓
Works                           →  Professional Experience
Completes a project             →  Work Proof ✓
```

```
LEARNING → SKILLS → PROOF → WORK → REPUTATION → GROWTH
```

All inside one ecosystem, under one [Kogia ID](kogia-id.md).

## Where the entries come from

| Source | Division |
|---|---|
| Learning record | [Education](../divisions/education.md) |
| Verified skills | [Skills](../divisions/skills.md) — Kogia Proof |
| Completed jobs | [Business](../divisions/business.md) |
| Challenges and reasoning | [Play](../divisions/play.md) |

A job completed in Kogia Business becomes proof in the worker's Passport. That loop
is the reason the divisions belong in one company.

## Non-negotiable constraints

1. **The person owns it.** They can export it, correct it, and delete it.
2. **Every claim is decomposable.** A verified skill shows what verified it.
3. **Disputable.** A person can challenge any entry.
4. **Consent per surface.** Being in Education does not publish anything to employers.
5. **Not a credit score.** A single opaque number about a human being, computed by a
   model, is a liability — legally and ethically.

## State

**Not built, and correctly so.** A Passport with nothing in it is a database table.
It becomes real when Education and Skills both have users — and it is designed for
now so that it remains possible.
