## The build rule

> Platform is **target architecture**. It is built gradually, when real users make it
> necessary — never as a prerequisite for the first product.

Building the platform first is how a company spends two years and ships nothing.
Building it never is how a company ends up with four products that cannot talk to
each other.

The discipline: **design as if Kogia ID exists; do not rewrite working systems to
adopt it before there is a reason.**
