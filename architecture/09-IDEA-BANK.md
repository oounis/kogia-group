# 09 — Idea Bank

Every idea lives here until it earns a place. **No domain, no logo, no repository.**

This file exists because ideas are not the scarce resource — finished products with
paying users are. Writing an idea down is how it stops demanding to be built today.

## The rule

An idea leaves this bank only by passing the [lifecycle](05-LIFECYCLE.md) gates:
Research verifies the problem → a landing page attracts interest → Labs builds an
MVP → ten people use it → one person pays.

## ⛔ Explicitly not now

**Kogia Social Network.** Not now, and not for a long time.

Utility brings people; community forms around them. Never the reverse. If Kogia one
day has 100K learners, 50K skilled workers and 20K parents, a community will appear
on its own. Building a social network and then looking for people is the most
reliable way to build nothing.

**Kogia Wallet.** A points, rewards and billing layer — not a bank, not crypto.
Genuinely interesting, and **later**. Stored value and payments can trigger
regulatory requirements depending on implementation and country. Not a thing to
stumble into.
