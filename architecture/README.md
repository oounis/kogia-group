# Kogia Group — Architecture

**Technology for Human Progress.**

This folder is the constitution of Kogia Group. It describes the company as a
structure that should survive twenty years, not as a list of the products that
happen to exist today. Products change, fail, merge and get replaced. The
structure does not.

Adopted **2026-09-12**, the same day the company was cut from 32 repositories to 7.
That cut is the reason this exists: Kogia had been growing by accumulation — a new
name, logo, domain and repository for every idea — and it produced fourteen
repositories that contained nothing but a name.

## The one thing to remember

> A division is not created because there is an idea.
> A division is created when there is an independent business area,
> with users, with value, and with a path to revenue.

Everything else is an experiment, and experiments live in
[Research](divisions/research.md) and the [Idea Bank](09-IDEA-BANK.md) — with no
domain, no logo and no repository until they have earned one.
