# Kharbga War Council — visual review V1

This is the promoted first visual candidate. Its product layout and finish remain useful, while its chess-like ranked-piece concept is retained only as a record of the first direction.

The new direction uses the product hierarchy of a mature online board-game service—board first, compact player rows, clocks, one action panel, responsive continuity—without copying Chess.com artwork, code or branding. Its art ratio is 60% imagined North-African Kharbga war-council craft and 40% Kogia curiosity, warmth and marine/copper color language.

The review deliberately exposes two rule directions:

- **War Council 8×8:** the requested chess-like new game with six original roles.
- **Heritage 7×7:** the traditional two-equal-armies structure, using only Footguards.

This prevents a visual redesign from silently rewriting the game rules.

All generated delivery assets are 512×512 RGBA PNGs. The original chroma-key boards remain under `direction-boards/` and the final prompt set is recorded in `PROMPTS.md`.
