# Faz3a V1 — Product Visual Review

Faz3a-specific review derived from the repository PRD, domain model, proximity thresholds, mobile theme and the five supplied mobile design captures.

The eighteen categories cover the complete action loop: nearby alert, lightweight report, convergence, guided arrival, short-lived coordination, before/after evidence, independent verification and verified impact. Iris `#6C4DE6` is the product/action colour. Green is reserved for arrived/verified, amber for pending/approaching and red for rejection or safety.

Partner and sponsor placements are restricted to discovery and institutional surfaces. They never appear over an urgent alert, live guidance, evidence capture or verification decision.
